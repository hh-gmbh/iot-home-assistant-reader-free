# Home Assistant Reader free

Nur lesende Ansicht ausgewählter Home-Assistant-Dashboards im Browser, ohne Zugang zu Home
Assistant selbst. Eine App der Hammerherren GmbH, Bereich IoT.

## Installation

1. In Home Assistant: **Einstellungen → Apps → App-Store → ⋮ → Repositorys**
2. Diese Adresse hinzufügen:
   ```
   https://github.com/hh-gmbh/iot-home-assistant-reader-free
   ```
3. **Home Assistant Reader free** im App-Store auswählen, installieren und starten.

Beschreibung, dargestellte Karten und Hinweise zum Zertifikat finden Sie in der App unter **Info**
und **Dokumentation** sowie in [`ha_reader_free/README.md`](ha_reader_free/README.md) und
[`ha_reader_free/DOCS.md`](ha_reader_free/DOCS.md).
